About this studio

Process films are progress sequences of physical paintings — not AI generations. Each frame is a photo of the work mid-way; the edit only crops, steadies, and quickens the pace for the site.

Living paintings start as handmade work. Grok animates the finished painting so the piece can move while staying true to the brushstrokes on the canvas.
